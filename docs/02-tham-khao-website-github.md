## C. Tài nguyên hình ảnh, âm thanh, font miễn phí

- **Kenney** ([kenney.nl](https://kenney.nl)) — hàng nghìn asset 2D, isometric, 3D, UI, âm thanh, giấy phép **CC0** (dùng tự do).
- **Quaternius** ([quaternius.com](https://quaternius.com)) — mô hình 3D low-poly CC0.
- **Fluent Emoji** — MIT, có kiểu 3D, màu, phẳng.
- **Google Fonts** có hỗ trợ tiếng Việt: *Baloo 2* (tiêu đề tròn trịa), *Nunito*, *Quicksand*.
- **OpenGameArt**, **Freesound**, **LottieFiles** — nhiều tài nguyên miễn phí nhưng **giấy phép khác nhau theo từng file**, phải kiểm tra và ghi nguồn.
